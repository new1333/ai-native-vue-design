# 页面构建块

构建块（Block）是由多个纸面组件拼装成的**页面级组合**：登录页、数据仪表盘、AI 工作台……每一块都是自包含的单文件 Vue SFC——只依赖 `@ui/components` 与 `@ui-*` token，复制到你的项目即可作为页面起点。

每个构建块页面提供：

- **整页活预览**：满宽舞台渲染真实组件（非截图），可切换桌面 / 平板 / 手机宽度；
- **源码同源**：预览与「查看源码 / 复制源码」来自同一份文件，所见即所得；
- **主题联动**：视觉全部走 `--ui-*` token，跟随纸面浅色 / 夜纸深色自动切换。

## 使用方式

1. 确认项目已按[快速开始](/guide/quickstart)接入：入口引入 `@ui/tokens/paper.css`，组件从 `@ui/components` 按需导入；
2. 在构建块页面点「复制源码」，粘贴为如 `src/blocks/LoginBlock.vue`；
3. 在路由中挂载，或抽出局部（如只要表单区）自行裁剪——块内没有隐藏依赖。

::: tip
构建块是「拿来改的起点」而非黑盒组件：所有交互（校验、分页、发送消息）都是可读的演示实现，替换成你的真实接口即可。
:::
